## 转机接续与摆渡运输

地勤完成不再等于可以直接离港：带转机关系的旅客批次必须先形成确定去向。

- **赶上判定是完整流水线**：实际靠桥时刻（`parkedAt`）→ 下客 → 转机安检（随人数/机型变化）→
  远机位摆渡或廊桥步行 → 登机口截止（计划离港前 25 秒）。前序航班的预计到达不会被直接当作可登机。
- **有限等待**：每批旅客可申请一次最长 60 秒等待，且不晚于登机截止；到期仍未运输自动按误机处置。
  等待会延后该机位释放，面板会列出受影响的后续接机。
- **放弃等待**：未运输旅客立即误机并生成带 `RT-xxxx` 编号的安置单（改签 / 酒店 / 退票凭证），
  已登车与已登机的人不受影响。
- **两种发车**：普通班（12 座，小批多趟，单趟成本高）与集中快车（18 座，需凑满 14 人，班次成本低）。
  登车即生成不可变载客快照，运行中更改等待决定不会让人消失或被重复计算。
- **离港门禁**：地勤三项完成且所有关联转机批次闭环（已登机或已误机）后才允许推出。
- **存档 v2**：读回的班次可逐批核对人数与安置单，严格校验包含人数守恒、在途快照与台账对账等不变量。
